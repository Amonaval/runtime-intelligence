## Reproduce

```bash
npm run lab:react:hostile:install
npm --prefix examples/react-uninstrumented-lab install --no-save playwright
cd examples/react-uninstrumented-lab
npx playwright install chromium
npm run accept:browser -- /absolute/path/to/results
```

Stop an existing hostile dev server first; the runner starts its own strict-port server. Optional environment overrides: `RI_PLAYWRIGHT_MODULE` (module import path), `RI_CHROMIUM_EXECUTABLE`, and `RI_CHROMIUM_ARGS` (JSON array). Browser tooling is validation-only and excluded from the shipped package. The receipt and downloaded reports are written to the selected output directory.
