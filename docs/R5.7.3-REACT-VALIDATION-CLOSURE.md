# R5.7.3 — React Fault-Lab Validation Closure

## Evidence that triggered this patch

The one-pass React Fault Lab report proved broad behavioral detection, but exposed four trust/quality gaps:

1. the behavioral three-request sequence did not produce a sequential-API opportunity when other network scenarios were running concurrently;
2. normalized findings/opportunities repeated the same semantic issue across repeated detections;
3. derived diagnostics could lose useful source/provenance metadata;
4. Intelligence could present an unrelated temporal neighbor as the strongest causal-looking signal.

## Changes

- Network entries now expose explicit `startedAt` / `endedAt` timestamps for fetch and XHR.
- Sequential API analysis groups calls by originating stack and scans sequential subsequences, so unrelated concurrent calls cannot suppress a valid chain.
- Normalized JSON/HTML reports semantically deduplicate findings/opportunities while retaining raw evidence and raw counts. Each normalized entry includes `occurrenceCount` and `eventIds`.
- Report rows identify `observed` versus `synthetic` origin.
- Update-budget diagnostics preserve the source/framework/correlation metadata of the render evidence that triggered the budget finding.
- The synthetic lifetime fixture emits an explicitly synthetic lifetime diagnostic rather than relying on a derived bridge diagnostic that could lose provenance.
- Correlation-only Intelligence now says `Related signal` / `temporal co-occurrence only`; it does not present that relationship as a likely contributor.

## Acceptance rerun

Use React Fault Lab → **Run all + export JSON + HTML**.

Acceptance requires:

- a non-synthetic `sequential-api-opportunity` from the behavioral request loop;
- unique high-level findings/opportunities with occurrence counts instead of repeated rows;
- synthetic fixtures visibly retain synthetic origin;
- real update-budget findings retain React component source when available;
- correlation-only Intelligence does not imply causality/contribution.

Raw UREP evidence remains intentionally complete and may contain repeated observations; deduplication applies only to the human-facing normalized report layer.
