# R5.7.4 — First-Class Opportunities Tab

## Goal

Expose Runtime Intelligence opportunities as a first-class mature-panel workflow instead of making developers discover them indirectly through Pinpoint, Intelligence, Falcor sections, or exported reports.

## Architecture

The tab does **not** create a second opportunity engine.

```text
UREP diagnostics
    ↓
createRuntimeReport().opportunities
    ↓
runtime-opportunities-model
    ↓
⚡ Opportunities tab
    ↓
Pinpoint / Network / Perf drill-down
```

The same deduplicated normalized opportunity collection therefore powers both live UI and JSON/HTML exports.

## What the tab shows

- unique opportunity count in the tab label
- observed vs synthetic origin
- High / Medium / Low product priority
- category: Performance, Network, Rendering, Scheduling, Memory
- evidence level
- occurrence count for semantically deduplicated observations
- owner/component when known
- source file/line when defensible
- concise observed facts rather than raw payload JSON
- framework-aware recommendation from the normalized report contract
- deep links into mature evidence views

## Filters

- Category
- Origin: all / observed / synthetic
- Evidence level

Synthetic findings are expected only in validation labs and remain explicitly labeled.

## Navigation

| Opportunity | Drill-down |
| --- | --- |
| Sequential APIs | Network |

| Virtualization | Pinpoint |
| Expensive paint | Pinpoint |
| Worker candidate | Pinpoint |
| Idle scheduling | Pinpoint |
| Resource lifetime | Pinpoint |

## Performance hygiene

Evidence events only mark the opportunity badge/model as dirty. The full normalized opportunity model is recomputed on the panel's coalesced Lit update rather than synchronously for every evidence event. This avoids making Runtime Intelligence itself materially noisier during fault storms.

## Framework neutrality

The presentation consumes normalized opportunities, not React-specific collectors. Future Vue/Angular adapters can emit the same UREP diagnostic flags and automatically use the same tab, filters, priorities, recommendations, exports, and drill-down behavior.
