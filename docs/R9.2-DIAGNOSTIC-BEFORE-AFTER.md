# R9.2 — Diagnostic Before/After Experience

## Status

IMPLEMENTED in source. The mission turns the existing workflow baseline/compare/verify primitives into one bounded developer flow without changing R9.1 causality semantics.

## Developer flow

```text
reproduce problem
  → capture baseline
  → apply intended fix
  → replay the same workflow
  → capture replay
  → improved / unchanged / regressed / inconclusive
```

The experience is framework-neutral and reads from the same shared UREP `EvidenceStore` used by React, Vue and Lit.

## Public API

`runtime-intelligence/panel` now exports:

- `DiagnosticBeforeAfterStatus`
- `createDiagnosticBeforeAfterSession(...)`

The canonical panel mount also exposes:

- `startBeforeAfter(...)`
- `getBeforeAfterState()`

Example:

```js
import { MetricDirection } from 'runtime-intelligence/core';

const session = panel.startBeforeAfter({
  workflowId: 'save-product',
  target: {
    metricId: 'count:error',
    direction: MetricDirection.DECREASE,
  },
  intervention: {
    id: 'fix-save-race',
    description: 'dedupe duplicate save request',
    applied: true,
  },
});

// Reproduce the problem first.
session.captureBaseline();

// Apply the intended fix, then replay the same workflow.
session.captureReplay();

console.log(session.getState());
```

Custom workflow metrics supported by `createWorkflowRun(...)` can be supplied through the `metrics` option.

## Status semantics

### `awaiting-baseline`

No comparison exists yet. Reproduce the target workflow and capture the baseline.

### `awaiting-replay`

The baseline exists. Apply the intended fix, replay the same workflow and capture the replay.

### `improved`

The configured verification target met its threshold.

This does **not** automatically mean the intervention caused the improvement. Without separate governed causal evidence the underlying verification remains:

- `verificationConfirmed: true`
- `causalityConfirmed: false`
- `evidenceLevel: correlation`

### `unchanged`

The replay did not meet the configured improvement threshold. This includes zero change and positive movement that remains below the declared threshold.

### `regressed`

The target moved in the wrong direction.

### `inconclusive`

The comparison cannot support a useful conclusion, for example because the intervention was not confirmed applied, the target metric is unavailable or the workflow/run identity is invalid.

## Reporting

When a session is started through the canonical panel mount, `createReport()` attaches the current state as `diagnosticBeforeAfter`.

JSON exports therefore preserve:

- workflow/target/intervention metadata;
- bounded baseline and replay workflow snapshots;
- target before/after values;
- improvement and relative improvement;
- verification outcome/evidence level;
- explicit causality flag;
- developer-facing headline, next action and evidence note.

HTML reports render a dedicated **Diagnostic before / after** section with the same evidence boundary.

The existing report privacy sanitizer still applies to the complete export. No raw runtime payload boundary is widened.

## Compatibility

The mission is additive:

- no existing public export was removed or renamed;
- no UREP schema version change;
- no framework adapter change;
- no telemetry/background upload;
- no TrustWeave changes;
- no Angular work.

## Validation scope

Focused unit coverage was added for:

- baseline → replay guided state transitions;
- meaningful improvement remaining correlation-level under R9.1;
- unchanged/below-threshold result;
- regression;
- inconclusive result;
- replay-before-baseline guard;
- reset behavior;
- immutable/JSON-safe state;
- JSON report inclusion;
- HTML report rendering with explicit `causality not confirmed` wording.

The full repository release gate should be rerun in a normal checked-out development environment before treating R9.2 as fully release-validated.

## Boundaries

R9.2 is not an experiment platform and does not add statistical causal inference. It makes existing diagnostic verification easier to use and interpret.

TrustWeave remains parked. R10 Angular remains deferred.
